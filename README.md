# 🚐 Proyecto Belmonte

## Descripción

Proyecto Belmonte es una aplicación móvil para Android desarrollada en Kotlin, diseñada para facilitar la gestión de usuarios y traslados mediante una interfaz sencilla, intuitiva y fácil de utilizar.

La aplicación integra herramientas que permiten organizar la información, gestionar los traslados y navegar entre las distintas pantallas de manera clara y ordenada. Para el almacenamiento local de datos utiliza Room, mientras que ViewModel y Repository ayudan a separar las responsabilidades y mantener una estructura de código organizada.

El proyecto incorpora pruebas de software y utiliza Gradle para la compilación y administración de dependencias. Su desarrollo busca aplicar buenas prácticas de programación, mejorar la mantenibilidad del código y ofrecer una experiencia de usuario fluida.

## Tecnologías utilizadas

- **Kotlin:** lenguaje de programación principal.
- **Android Studio:** entorno de desarrollo.
- **Room:** persistencia de datos local.
- **ViewModel:** gestión y conservación del estado de la interfaz.
- **Repository:** organización del acceso a los datos.
- **Gradle:** compilación y administración de dependencias.
- **Git y GitHub:** control de versiones y almacenamiento del código fuente.

## Objetivo del proyecto

Desarrollar una aplicación Android que permita gestionar usuarios y traslados de forma organizada, aplicando conceptos de arquitectura de software, persistencia de datos, navegación, pruebas y control de versiones.

## Ejecución

Para ejecutar el proyecto, abre la carpeta en Android Studio, espera a que finalice la sincronización de Gradle y ejecuta la aplicación en un emulador o dispositivo Android compatible.
